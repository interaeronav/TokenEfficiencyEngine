## Fab and asset sources

**Fab** is Epic's unified content marketplace, succeeding the Unreal Marketplace and the Quixel storefront. Free content is found via the filter menu → *Price > Free*.

Licence tiers, as published in the Fab EULA:

| Tier | What it grants |
|---|---|
| **Personal** | Same scope of rights as Professional; access to assets in **source format** |
| **Professional** | Identical permissions to Personal; source format. Epic states there is **no need to upgrade from Personal to Professional if you cross the revenue threshold after purchase** |
| **Reference-Only** | Access to the content only as a **referenced asset**, not its source format |
| **CC-BY** | Governed by Creative Commons terms, not Fab's |

All standard tiers permit commercial or private use, modification for incorporation into a project, commercial distribution of a project containing the asset, use with any compatible tool, and sharing with project collaborators. All prohibit standalone resale or redistribution of the asset itself.

> ⚠️ "Free" on Fab is not the same as "unrestricted". Read the tier attached to each item. Reference-Only content cannot be modified at source, which rules it out of some archviz workflows.

For a Namibian project, expect Megascans to cover ground surfaces, rock, generic dry grass and desert scatter well, and to cover indigenous species (makalani palm, marula, mopane) poorly. Budget for modelling or purchasing those separately, or for modifying generic palms and acacias.

## A suggested learning order for this project

1. **Editor navigation and the object model** — Unreal Sensei's beginner series, then this domain's files `01` and `02`.
2. **Datasmith import** — bring the actual project model in badly, then read file `02` and do it properly.
3. **Lighting** — William Faucher's Lumen and lighting videos, then file `04`'s sun and physical-units sections. Set up the Okongo SunSky and produce a sun study before touching materials.
4. **Materials** — master materials and instances (file `03`). Resist the urge to author fifty unique materials.
5. **Cameras and Movie Render Queue** — file `04`. Produce one finished still before attempting a walkthrough.
6. **Python automation** — file `06`. Automate the reimport-and-reassign loop, because you will run it dozens of times.
7. **MCP** — enable the 5.8 plugin, connect Claude Code, and write one project-specific toolset (file `06`).
8. **Interactivity** — Blueprint (file `05`) only once the stills are good. A beautiful still sells the project; a mediocre interactive walkthrough does not.
