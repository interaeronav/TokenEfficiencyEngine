## Pipeline anatomy (image → GLB)

- **Entry**: `trellis2/pipelines/trellis2_image_to_3d.py` — `Trellis2ImageTo3DPipeline.run()` (line 488); orchestration order: preprocess → cond → sparse structure → shape SLat → tex SLat → decode → (render) → GLB. Pipeline types `'512' | '1024' | '1024_cascade' (default) | '1536_cascade'` (lines 517-534); `low_vram=True` swaps each model CPU↔GPU around its call.
- **Stage 1 — preprocessing/rembg**: `preprocess_image()` (trellis2_image_to_3d.py:127-162): if input has a real alpha channel, rembg is skipped entirely (lines 131-141); else a BiRefNet-architecture segmenter (`trellis2/pipelines/rembg/BiRefNet.py`, HF `trust_remote_code=True` at line 10). Configured weights are **briaai/RMBG-2.0** per HF `pipeline.json` — not the code default `ZhengPeng7/BiRefNet` (BiRefNet.py:9). Crop/rescale to alpha bbox, RGB premultiplied. Dense GPU only; hard-coded `"cuda"` at BiRefNet.py:33.
- **Stage 2 — conditioning**: `DinoV3FeatureExtractor` (`trellis2/modules/image_feature_extractor.py:59-118`) wrapping `transformers.DINOv3ViTModel` (line 5), model `facebook/dinov3-vitl16-pretrain-lvd1689m` per pipeline.json; run at 512 and 1024 px (trellis2_image_to_3d.py:539-540). A `DinoV2FeatureExtractor` (torch.hub) exists (line 10) but is unused by the shipped config. `.cuda()` hard-coded at lines 49/53/112/116.
- **Stage 3 — sparse structure**: `sample_sparse_structure()` (trellis2_image_to_3d.py:188-235). Dense DiT `SparseStructureFlowModel` (`trellis2/models/sparse_structure_flow.py:56`; 16³ latent, 8ch, 1536w, 30 blocks, RoPE per `configs/gen/ss_flow_img_dit_1_3B_64_bf16.json`), sampled by `FlowEulerGuidanceIntervalSampler` (12 steps). Latent decoded to 64³ occupancy by **TRELLIS v1's** `SparseStructureDecoder` (`trellis2/models/sparse_structure_vae.py:210`) whose checkpoint is pulled cross-repo from `microsoft/TRELLIS-image-large/ckpts/ss_dec_conv3d_16l8_fp16` (pipeline.json; fallback load path `trellis2/pipelines/base.py:43-46`). Dense attention has `sdpa`/`naive` fallbacks (`trellis2/modules/attention/full_attn.py:124-141`, config.py:15).
- **Stage 4 — shape SLat**: `sample_shape_slat[_cascade]()` (trellis2_image_to_3d.py:237-364). Sparse DiT `SLatFlowModel` (`trellis2/models/structured_latent_flow.py:15`) — SparseLinear + full varlen sparse attention (`attn_mode='full'`, line 72); no sparse conv in the DiT. Cascade: 512-res sample → decoder `upsample()` (`trellis2/models/sc_vaes/sparse_unet_vae.py:509`) → token-budget resolution backoff (max_num_tokens 49152) → 1024-model resample. Needs sparse varlen attention — **only xformers/flash_attn/flash_attn_3 backends in-tree, no SDPA fallback** (`trellis2/modules/sparse/attention/full_attn.py:172-215`).
- **Stage 5 — decode to mesh**: `decode_shape_slat()` → `FlexiDualGridVaeDecoder` (`trellis2/models/sc_vaes/fdg_vae.py`), a sparse ConvNeXt/U-Net VAE (16× upsample, f16c32) whose convs dispatch via `trellis2/modules/sparse/conv/conv.py` to backend `flex_gemm` (default), `spconv`, or `torchsparse`; then `flexible_dual_grid_to_mesh` (fdg_vae.py:20,90,103 → `o-voxel/o_voxel/convert/flexible_dual_grid.py:142`) which calls **CUDA-only** hashmap kernels `_C.hashmap_insert_3d_idx_as_val_cuda` / `_C.hashmap_lookup_3d_cuda` (lines 226, 236). `Mesh.fill_holes()` (trellis2_image_to_3d.py:474 → `trellis2/representations/mesh/base.py:35`) uses **cumesh** (CUDA).
- **Stage 6 — PBR texture**: `sample_tex_slat()` (trellis2_image_to_3d.py:391) — second sparse DiT conditioned on shape SLat (channel-concat); decoded by `tex_slat_decoder` (sparse U-Net VAE) into per-voxel attrs, layout base_color(3)+metallic(1)+roughness(1)+alpha(1) (lines 73-78). Output = `MeshWithVoxel` (mesh + sparse attr volume).
- **Stage 7 — render (optional preview only)**: `trellis2/utils/render_utils.py` → `PbrMeshRenderer`/`MeshRenderer`/`VoxelRenderer`. nvdiffrast lazily imported (mesh_renderer.py:45,85; pbr_mesh_renderer.py:22,57,199,241); split-sum env lighting from `nvdiffrec_render.light.EnvironmentLight` (pbr_mesh_renderer.py:46); voxel preview uses the in-tree CUDA rasterizer (`o-voxel/src/rasterize/rasterize.cu`).
- **Stage 8 — export**: `o_voxel.postprocess.to_glb()` (`o-voxel/o_voxel/postprocess.py:14`; called from app.py:493 and the README example): cumesh fill_holes/simplify/optional narrow-band-DC remesh + `uv_unwrap` (xatlas-based), `cumesh.cuBVH` attr re-projection (lines 122, 254), **nvdiffrast `RasterizeCudaContext`** UV-space bake (lines 230-249), `flex_gemm.ops.grid_sample.grid_sample_3d` trilinear sampling of the sparse attr volume (line 260), cv2 TELEA inpaint of seams, trimesh `PBRMaterial` → GLB (WebP textures optional). **Shape-conditioned texturing** is a separate pipeline `trellis2/pipelines/trellis2_texturing.py` importing cumesh/nvdiffrast/flex_gemm at module level (lines 12-15).

## Custom/compiled extension inventory

- **`o_voxel._C`** (in-tree, MIT, `o-voxel/setup.py` builds CUDAExtension; HIP/ROCm supported): `src/hash/hash.cu` (GPU spatial hashmap — CUDA-only bindings), `src/convert/flexible_dual_grid.cpp` + `volumetic_attr.cpp` (**CPU**, Eigen QEF solve — mesh→O-Voxel data prep), `src/serialize/{z_order,hilbert}.cu` (**both** `_cpu` and `_cuda` bindings, `src/ext.cpp:20-27`), `src/io/svo.cpp` etc. (CPU SVO codecs for `.vxz`), `src/rasterize/rasterize.cu` (CUDA voxel rasterizer). Fallback summary: serialize/io/convert-to-voxel have CPU paths; **hash and rasterize do not**. Eigen vendored as a git submodule (`.gitmodules` → gitlab.com/libeigen/eigen, MPL-2.0), empty in a non-recursive clone.
- **flex_gemm** (external, JeffreyXiang/FlexGEMM, **MIT**, pure Triton ≥3.2): `sparse_submanifold_conv3d` (conv_flex_gemm.py:6-7) and `grid_sample_3d`. Triton targets CUDA/ROCm — no MPS.
- **cumesh** (external, JeffreyXiang/CuMesh, **MIT top-level but vendors `third_party/cubvh`**, whose `LICENSE_NVIDIA` is the NVIDIA instant-ngp Source Code License — **non-commercial**; also `third_party/xatlas`, MIT). CUDA-only (CUDA 12.4+). Imported at representations/mesh/base.py:4, trellis2_texturing.py:12, postprocess.py:11.
- **nvdiffrast** v0.4.0 (external, NVlabs; **NVIDIA Source Code License 1-Way Commercial — "used or intended for use non-commercially"**, verified from LICENSE.txt). CUDA-only per setup.sh:103-111.
- **nvdiffrec_render** (external, `JeffreyXiang/nvdiffrec` branch `renderutils`, fork of NVlabs/nvdiffrec — **NVIDIA Source Code License, non-commercial**). Single import site: pbr_mesh_renderer.py:46 (preview lighting only).
- **flash-attn 2.7.3** (BSD-3) / **flash_attn_interface (FA3)** / **xformers** (BSD-style) — attention backends, CUDA-only. **spconv** (Apache-2.0) / **torchsparse** (MIT) — alternative sparse-conv backends. No `conv_none.py` exists despite config listing `'none'` — **no pure-PyTorch sparse conv in-tree**.
- Windowed/shifted-window sparse attention exists (`windowed_attn.py`) but no shipped config uses it (grep of `configs/` = zero hits); shipped DiTs are all `attn_mode='full'`.

## Dependency + license inventory (runtime vs training)

- **Runtime, NOT MIT-clean**: **nvdiffrast** (NVIDIA non-comm), **nvdiffrec_render** (NVIDIA non-comm), **cumesh→cubvh** (NVIDIA instant-ngp non-comm inside an MIT wrapper), **plyfile** (**GPLv3+**, PyPI-verified; imported at o-voxel/o_voxel/io/ply.py:5 — pulled in by `o_voxel.io.__init__` unconditionally — and trellis2/utils/mesh_utils.py:6, which nothing imports), **easydict** (**LGPL-3.0**, PyPI-verified; ~25 import sites incl. renderers and samplers).

- **Training/data-prep only**: lpips (imports only in `trellis2/utils/loss_utils.py:5` ← trainers), tensorboard, pandas, gradio 6.0.1 (demo apps only), bpy/mathutils/io_scene_usdz (data_toolkit/blender_script), open3d, objaverse, open_clip_torch (data_toolkit/setup.sh). None load at inference.

## Relationship to TRELLIS v1

- v1 (microsoft/TRELLIS, MIT, 13.5k stars, last major update 2025-03-25): SLAT decoded to **3D Gaussians, radiance fields, and FlexiCubes meshes**; deps included kaolin, modified FlexiCubes, diffoctreerast (all NVIDIA/non-MIT), spconv, DINOv2.
- v2 **reuses v1 code and one v1 checkpoint**: `trellis2/models/sparse_structure_vae.py` is class-for-class identical to v1's (verified against raw GitHub, including docstrings citing the v1 paper's "Sec. 3.3"), and the shipped pipeline downloads v1's `ss_dec_conv3d_16l8_fp16` decoder. The sparse-tensor/transformer framework and pipeline/sampler layout are an evolved copy of v1's.
- What changed: all field/NeRF/GS decoders replaced by **O-Voxel flexible-dual-grid** native mesh+volumetric-PBR (new `o-voxel` package, new SC-VAEs), FlexiCubes/kaolin/diffoctreerast dropped, conditioning DINOv2→DINOv3, rembg→BiRefNet/RMBG-2.0, default sparse conv spconv→FlexGEMM (Triton), cascaded 512→1024/1536 generation, separate texture DiT + texturing pipeline, RoPE + qk-RMS-norm DiTs.

## What a clean-MIT fork must replace/exclude (minimal set)

- **Safe to vendor verbatim (Microsoft MIT)**: everything under `trellis2/` and `o-voxel/` (code + kernels), `configs/`, `train.py`, apps; Eigen submodule (MPL-2.0, header-only — keep headers/notice); TRELLIS.2-4B and TRELLIS-image-large weights (both MIT — can mirror).
- **Replace (runtime path)**: (1) **nvdiffrast** — the only load-bearing uses are UV-space bake rasterization in `o_voxel/postprocess.py:230-249` and preview renderers; a small pure-PyTorch UV rasterizer suffices for baking. (2) **cumesh** — swap for an MIT stack: xatlas-python (UV), trimesh + a clean BVH for re-projection, or vendor CuMesh minus `third_party/cubvh`. (3) **RMBG-2.0 weights** — swap to MIT BiRefNet weights (ZhengPeng7) or make alpha-input mandatory (the RGBA path already bypasses rembg, trellis2_image_to_3d.py:131-141). (4) **plyfile** — replace `.ply` IO with trimesh or drop. (5) **easydict** — ~50-line MIT reimplementation. (6) **Exclude entirely**: `nvdiffrec_render` (preview lighting only).
- **Break the import chain first**: `o_voxel/__init__.py` eagerly imports `postprocess` (→ nvdiffrast+cumesh+flex_gemm) and `io` (→ plyfile); `representations/mesh/base.py:4-5` imports cumesh+flex_gemm at module level. Lazy-import these and the generator core is import-clean.
- **Accept with terms**: DINOv3 weights (commercial-OK but gated + "Built with DINOv3" attribution + AUP — the 4B DiTs are trained against DINOv3 features, so it cannot be swapped without retraining).

## Implications for the build

1. **The taint is confined to pre/post-processing, not the generator.** All five neural stages are MIT code + MIT weights. Replacing the exporter's rasterizer (nvdiffrast), the mesh toolkit (cumesh/cubvh), and the rembg weights (RMBG-2.0) yields a fully commercial-clean runtime — no model retraining needed.
2. **Do the import-chain surgery on day one** (`o_voxel/__init__.py`, `o_voxel/io/__init__.py`, `representations/mesh/base.py`): it decouples generation from the tainted/CUDA-only export stack and makes the MPS port testable incrementally.
3. **MPS port scope, ranked by difficulty**: (a) sparse varlen attention — add an SDPA fallback mirroring the dense one at `modules/attention/full_attn.py:124-141` (the sparse module lacks it); (b) FlexGEMM sparse conv + `grid_sample_3d` — Triton has no MPS backend; need a gather-GEMM PyTorch implementation (SC-VAE decode is the hot spot); (c) `o_voxel._C` hash kernels in `flexible_dual_grid_to_mesh` — replaceable with `torch.unique`/`searchsorted`; (d) sweep ~20 hard-coded `.cuda()`/`device='cuda'` sites; (e) CPU paths already exist for serialize/SVO/mesh→FDG.
4. **On 128 GB unified memory, delete `low_vram`**: upstream ping-pongs 8 models CPU↔GPU per run; keeping all ~16.2 GB + DINOv3 + segmenter resident removes that latency entirely.
5. **Ship-weights strategy**: mirror TRELLIS.2-4B + the v1 ss-decoder (MIT) in one repo to kill the fragile cross-repo fallback (`base.py:43-46`); DINOv3 must be user-fetched (gated) or redistributed under the DINOv3 license with attribution — legal note required.
6. **Known-defect fix list matches upstream issue themes**: small surface holes (upstream mitigates with `fill_holes`), non-CUDA scattered-hole artifacts, black/specular spots, token-budget resolution backoff surprises (silent 1536→lower fallback, trellis2_image_to_3d.py:335-339) — make that explicit in agent-facing output.
7. **Treat upstream as frozen** (11 commits, stale since June 2026, 123 open issues): fork hard, don't architect for rebasing; the shipped configs use only full attention, so windowed-attention code can be dropped from the fork.
