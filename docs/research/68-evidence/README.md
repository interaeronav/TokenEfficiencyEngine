# Evidence for research doc 68 — the mechanical CAD lane (A66)

The session that planned `partkiln` (2026-09-02) ran seven read-only
discovery agents, a critic over their reports, three design drafts judged on
four axes, one synthesis, and three adversarial refuters that executed the
synthesis's load-bearing claims against the installed OCP 7.9.3.1.1 and the
tree. It then ran the P0a measurement scripts. Everything below is a
verbatim copy of those files from the session scratchpad (which expires);
only the file names changed. The three design drafts are **not** copied —
the synthesis is the judged result and the script (`CLAUDE_A66_SCRIPT.md`)
supersedes both. Binary probe outputs (`.brep`, `.glb`, `.step`, `.stl`,
`.dxf`, `.svg`) were not copied; every number they produced is in
`p0a-rows.json` or `docs/PROGRESS.md`.

All files date from 2026-09-02. Line references inside them (`file:line`)
are against the tree as it stood that day, before A66 P1+ landed.
