Roadmap: "Onshape MCP server" for agents that "fix failing features, update parameters" (https://www.onshape.com/en/blog/ai-artificial-intelligence-cloud-native-cad-pdm-platform).
- **Zoo**: KCL is MIT (`kcl-lib` crate, `KittyCAD/modeling-app` MIT); engine is hosted. Metering: "$0.50 per minute", "We now meter by the second at the same $0.50/min rate", failed calls free, 20 free min/month; "Zoo MCP does not have a separate subscription or flat per-tool-call fee … billed as API usage" (https://zoo.dev/blog/turning-on-billing-for-text-to-cad, https://zoo.dev/docs/faq). ## 4. Document/feature-tree models worth learning from

- **FreeCAD PartDesign**: "A PartDesign Body is intended to model a single contiguous solid"; Tip "is automatically set to the last feature created in the Body" and can be rolled back; Sketcher constraints are `Sketcher.Constraint('Coincident', geoId1, posId1, geoId2, posId2)` — pure integer indices (https://raw.githubusercontent.com/FreeCAD/FreeCAD-documentation/main/wiki/Sketcher_Workbench.md). TNP: "a shape changing its internal name after a modelling operation (pad, cut, union, chamfer, fillet…)"; 1.0 algorithm identifies/suggests/auto-fixes; best practice "Reference sketches to main planes or datum planes instead of solid faces" (https://github.com/FreeCAD/FreeCAD-documentation/blob/main/wiki/Topological_naming_problem.md; regression still open: https://github.com/FreeCAD/FreeCAD/issues/17041).
- **build123d**: Builder (`BuildPart/BuildSketch/BuildLine`, `Mode.ADD/SUBTRACT/INTERSECT/REPLACE/PRIVATE`, `Locations` nestable, `pending_faces`) vs Algebra (`+ - &`, `plane * location * shape`); "String based selectors have been replaced with standard python filters and sorting"; `edges(Select.LAST)`; caveat "a `ShapeList` from a selector is typically unordered" (https://build123d.readthedocs.io/en/latest/topology_selection.html). Units: `MM = 1`, `IN = 25.4 * MM`.
- **CadQuery**: string selectors `>Z |Z #Z %Plane >>Y[-2] and/or/not/exc`; warnings "If a face is not planar, selectors are evaluated at the center of mass … quite unexpected"; "Non-linear edges are not selected for any string selectors except type (%) and center (>>)" (https://cadquery.readthedocs.io/en/latest/selectors.html). Sketch API: face-based with `mode='a'|'s'|'i'|'r'|'c'`, edge-based needs `assemble()`, `tag="name"` persistent refs, constraints FixedPoint/Coincident/Angle/Length/Distance/Radius/Orientation/ArcAngle (https://cadquery.readthedocs.io/en/latest/sketch.html). Assembly constraints `"part1@faces@>Z"`.
- **FeatureScript**: "Determinism is a core principle … no concept of undefined behavior … cannot be influenced by external input, time, or randomness"; "Value semantics are used everywhere" (https://cad.onshape.com/FsDoc/intro.html); geometry referenced by queries evaluated at regen (`qCreatedBy(makeId("Front"), EntityType.FACE)`), "Queries are just little street signs pointing to certain geometry" (https://develop3d.com/product-design/tutorial-onshape-featurescript-101/); features declare `precondition {…}` parameter schemas.
- **KCL**: `tag = $edge1` on path segments, `fillet(radius=, tags=[getNextAdjacentEdge(edge1)…])`, `tolerance` default 1e-7 mm (https://zoo.dev/docs/kcl-std/functions/std-solid-fillet); `@settings(defaultLengthUnit = in)` at file top, default mm, literals `5in 3mm 90deg`, "Multiplying numbers which have unknown or incompatible units" warning, `number(Length)` param types (https://zoo.dev/docs/kcl-book/units_of_measurement.html); "Variables are not updated or looped over" — patterns instead of loops; click-edge→code-line mapping (https://zoo.dev/research/introducing-kcl).
- **OpenSCAD**: CSG-only (CGAL/Manifold), no fillet/chamfer, no STEP/B-rep — proves what a CSG-only command language can't express. **SolveSpace**: constraint solver + linkages, GPLv3.

## 6. Design rules for an AI-native CAD command language (each tied to an observed pathology)

1. **One batch = one feature list; no per-feature tool calls.** Pathology: faust-machines "One operation per tool call. Batching … crashes"; 89/80/109-tool surfaces; Onshape BTM JSON needing ~10 lines per parameter. Rule: accept an ordered list of typed features (`sketch→extrude→hole→fillet`) in one call, execute as one kernel transaction, return one diff.
2. **Every created entity is named at creation, never addressed by index.** Pathology: FreeCAD TNP ("internal name changes after pad/cut/fillet"), AgentsCAD face_id reallocation, CadQuery non-planar/non-linear selector surprises, TexoCAD "sketch constraint syntax trips up every model". Rule: KCL/FeatureScript-style `tag` on every segment/face/feature; selectors are declarative queries (`faces(created_by=extrude1, normal=+Z)`) re-evaluated at regen, with `deterministicIds` echoed back.
